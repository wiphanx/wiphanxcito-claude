# Wiphanxcito

Plugin de Wiphanx para Claude. Con él, Claude responde cómo funciona Wiphanx y qué se puede ofrecer, a partir de la base de conocimiento oficial que mantiene el equipo, y dice "no está documentado" en vez de inventar.

El conocimiento **no está en este plugin**: lo sirve el conector Wiphanx (`https://mcp.wiphanx.com/mcp`) y solo responde a personas habilitadas en Wiphanxcito, después de iniciar sesión.
