# Wiphanxcito para Claude

Plugin de Claude de [Wiphanx](https://wiphanx.com). Este repositorio tiene solo las instrucciones y la dirección del conector. **No tiene información de Wiphanx:** el conocimiento lo sirve el conector y solo responde a personas habilitadas, después de iniciar sesión.

## Instalación (una sola vez)

1. En Claude (web o escritorio): **Configuración → Capacidades** → prende **"Ejecución de código y creación de archivos"**.
2. **Personalización → Plugins → Añadir → Añadir marketplace** → escribe `wiphanx/wiphanxcito-claude`.
3. Instala **Wiphanxcito**.
4. En el plugin, pestaña **Conectores** → **Wiphanx** → **Conectar**. Se abre la pantalla de conexión del panel de Wiphanx: ingresa tu email y tu contraseña del panel, el código que te llega por mail, elige tus clubes y aprueba.
5. Listo. Pregúntale a Claude lo que quieras sobre Wiphanx.

Para que funcione, tu cuenta tiene que estar habilitada en Wiphanxcito. Si no lo está, pídeselo al equipo de Wiphanx.
